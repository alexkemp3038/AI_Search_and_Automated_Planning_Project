# AI_Search_and_Automated_Planning_Project
This two-person project is split into two parts:
1. A sudoku solver that can take both .txt and .csv sudoku files. A backtracking engine along with a chosen heuristic (MRV, Minimum Remaining Values) to make the solver more efficient. The document defines this problem as a CSP (Constraint Satisfaction Problem), compares a brute force search approach to a backtracking search approach. An A* search approach is also analysed in the document.
2. An automated planner for a lunar space mission using PDDL domains and missions. Objects involved in this mission includes rovers, landers, samples and pieces of data such as images and scans A domain is made that considers specific constraints and different states for each object. Two different missions are then mapped for this domain with its initial states to reach a specific goal. An additional domain is also made, extending on the idea of the initial domain. Astronauts and rooms for each rover are now added. The extended domain considers specific constraints for how astronauts move around rooms and how an astronaut must be in a certain room to be able to perform specific actions. This is all explained in the document, along with the results of testing its efficiency.
